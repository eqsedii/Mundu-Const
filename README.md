# Mundu Wangai Construction website

Static site (HTML, CSS, JS). No build step.

- `index.html`, `style.css`, `script.js`
- `assets/img` (logo, project photos), `assets/video/hero.mp4` (hero background)

## Publish on GitHub Pages
1. Upload all files to the `Mundu-Const` repo (keep `index.html` in the root).
2. Repo Settings > Pages > Deploy from a branch > `main` / root > Save.

Phone / WhatsApp: change `254718878924` in `index.html` and `script.js` if the number changes.
